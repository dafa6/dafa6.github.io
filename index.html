Notes on video model specifications

Working notes kept while reading vendor documentation for video generation models. Each set is written against a published parameter table and says which document a figure came from.

  • Free-seconds ledger — what a free allowance actually covers, and what draws it down.
  • No negative prompt — what to do when the API has no field for what you want left out.
  • Delivered size notes — what comes back, measured on the file rather than on the spec sheet.
